# 驗證紀錄

## 自動化

`node --test tests/core.test.cjs tests/package.test.cjs`：**8 項通過、0 失敗、0 跳過**（Windows）。

- 6 項核心測試：密度全域數量與局部配額、同源生命週期、密度邊界與種子、寬高比、無效／透明圖、來源唯一與色彩範圍。

## 瀏覽器功能

原始即時版完成 14 項瀏覽器檢查：真實選圖、WebGL 2、暫停／恢復的像素與時鐘、0/50/100% 密度、風速、三檔精細度、橫圖、無效檔案、拖放、全螢幕、快捷鍵、窄視窗、連播效能、無影片／無外部連線。

整理至產品目錄後另行確認：

- 真實選擇同一張私人測試圖，尺寸 1968 × 2464。
- 建立 17,713 個字符，預設 8,857 個脫落來源。
- 公開幾何範例建立 5,121 個字符、2,561 個脫落來源。
- 公開範例的播放時鐘、幀數及實際 GPU 畫面隨時間改變。
- 沒有 JavaScript 錯誤、CSP 違規或 WebGL 錯誤。
- 雙擊流程實際開啟 Chrome 獨立視窗；經原生視窗與畫面確認，不只依賴命令退出碼。
- README 截圖由公開幾何範例的實際播放器擷取，不含私人照片或瀏覽器個人資訊。

幀率受硬體、更新率、視窗、前景狀態與精細度影響。這是單一環境的短時量測，不是長時間壓力測試，也不是其他裝置的保證。

瀏覽器分頁隱藏時會停止推進動畫。測試時需讓頁面可見或使用測試焦點模擬；不能把背景暫停誤判為動畫故障，也不能把焦點模擬當成使用者前景視窗的證據。

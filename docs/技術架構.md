# 技術架構

## 資料流

```text
使用者選圖 / 拖入 File
  → Blob URL → Image 解碼
  → Canvas 縮小至字符網格並取樣 RGBA
  → core.js 建立字元、色彩、局部配額與時間排程
  → renderer.js 建立字型圖集及單一 GPU 頂點緩衝
  → requestAnimationFrame 更新時間
  → WebGL 2 頂點著色器計算位置／透明度
  → 片段著色器取樣字型、疊加輕微光暈
```

所有檔案都是靜態資源，直接開啟 `index.html` 即可運行。不載入套件、不編譯、不需要 HTTP 伺服器。

## 檔案職責

| 檔案 | 職責 |
|---|---|
| `core.js` | 可在 Node 與瀏覽器共用的純運算核心 |
| `renderer.js` | WebGL 2、字型圖集、GPU 字符生命週期 |
| `app.js` | 圖片解碼、控制項、播放時鐘、錯誤提示 |
| `index.html`、`style.css` | 繁中介面、響應式版面、CSP |
| `demo-image.js` | 可公開的程式繪製 SVG 範例，使用 data URI 以支援 file 模式 |
| `start_player.cmd` | 找尋 Chrome／Edge、編碼 file URI、開啟獨立視窗 |
| `tests/` | Node 內建測試，無額外依賴 |

## 圖像如何成為字符

取樣亮度使用 RGBA 的透明度與加權亮度；再以分位數拉開明暗，避免低反差圖整體發灰。字符集合為：

```text
 .,:;i!+*ox%#@M
```

亮度決定字符密度；色彩映射為冰青、電白及洋紅。不是把照片保留在底下再加一層飄動文字；畫面主體由字符直接重建。

字符網格以 960 × 1200 的邏輯畫布排版，依輸入寬高比等比例容納；視窗改變時只縮放繪圖，不必重新取樣。使用者改變精細度時才重建網格。

## 三條不可退化的視覺原則

### 1. 同源，不重複

每個可見字元有唯一來源 ID，GPU 每個來源只繪製一個 point sprite。它在飛行期移動到風場位置；結束後回到原位，先留空再淡入。不另外保留同一來源的完整字符當底圖，因此不會出現兩層拼接感。

### 2. 全幅均勻，不是片區輪播

以 8 × 8 字符的小格做**時間分層與配額平衡**。格內字元分配打散後的時間槽，各字保有自己的開始時間、速度與擾動相位。

小格不是共同觸發區，不共用一個區域主人，也沒有片區一起消失的事件。

### 3. 半密度是真正停用一半來源點

密度遮罩以全域 `Math.round(字元數 × 密度)` 為目標，再分配局部配額，按既有開始時間交錯抽樣。停用點一直留在原位，不發射飛字。

因此 50% 不是把同樣多碎片變淡，而是確實減少脫落來源，讓主體更清楚。字元數為奇數時使用 JavaScript 的四捨五入規則。

## 時間與風場

- 循環長度：8 秒。
- 每個字元獨立經歷：飛行 → 留空 → 緩慢再生 → 原位停留。
- 左向位移包含平滑起步與加速；上下以相位不同的正弦項擾動。
- CPU 的 `eventState()` 提供單元測試參考，GPU 使用相同生命週期概念。
- 分頁隱藏時不推進動畫，避免在背景持續消耗 GPU；重新顯示後繼續。

## 隱私邊界

原始 File 透過 Blob URL 解碼後就撤銷 URL，保留的是當前頁面的圖片及取樣資料。不寫入 localStorage、不上傳、不包含遠端服務金鑰。

CSP 禁止 `connect-src`，腳本與樣式全部來自本機。私有開發資料放 `.local/`；不應把私人照片轉成 base64 後誤當「程式碼」一併公開。

## 維護邊界

即時版是從已驗證的 Python 視覺原型移植而來；取樣與字型流程不同，不宣稱與原型逐像素一致。原型的 V1–V5 是視覺實驗階段，不是被補造的 Git 提交歷史。公開倉庫從可用的即時版 `v0.1.0` 開始管理。
